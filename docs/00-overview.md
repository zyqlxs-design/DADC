# DADC 异构数据底座最小验证总览

更新时间：2026-08-18

## 当前固定目标

当前最小目标不是一次性收集大量数据，也不是先做“可信数据集”。目标是验证智能体可长期使用的可扩展数据底座：外部数据能够被识别、保留原件、转换为冻结九实体、校验、判重、查询并追溯，且不同来源语义不混淆。

## 四个最小验证集

| 序号 | 器件/来源 | 关键异构点 | 工程实现状态 | 用户共享 warehouse |
|---:|---|---|---|---|
| 1 | HFSS 带通滤波器 | 两端口仿真、MA Touchstone、失败/重跑基础 | 完成 | 已入库 |
| 2 | PyAEDT 贴片天线 | 单端口仿真、自动建模求解、AEDT 原生证据 | 完成 | 已入库 |
| 3 | 厂商射频电感 | 实验 S2P、Windows-1252、PDF 文献、阻抗/L/Q 派生 | 完成并通过官方真实文件闭环 | 待执行一次下载/入库 |
| 4 | 薄膜功率电阻参考求解 | 电势/电场/损耗/温度/热流、网格、显式 one-way coupling | 完成并通过数值闭环 | 待与第 3 组一起入库 |

因此，工程实现闭环为 **4/4**；用户现有共享 warehouse 在执行第 3、4 组命令前仍为 **2/4**。不得把“适配器已验证”写成“用户仓库已经入库”。第 4 组是 DADC 参考求解器的真实数值计算，不是 Ansys、OpenFOAM 或 MFEM 求解结果。

## 第 3 组验收结果

- 官方样本：Würth Elektronik 744765056A，802 个频率点、2 端口；
- 单案例仓库：23 条实体记录、6 个 Artifact、8 个 HDF5 引用；
- 总校验：`valid: true`、`issues: []`；
- 31 个 Python 回归测试全部通过；
- `experiment_run`、`literature_record`、`data_processing` 三类活动严格分离；
- 原始 S 参数为 `raw_experiment_output`，手册规格为 `literature_extracted`，阻抗/L/Q 为 `calculated`；
- PDF 或 S2P 篡改会触发 SHA-256 完整性失败；
- 同字节测量文件再次入库会被判为 duplicate。

仓库格式与追溯总校验通过，不代表每项物理检查通过。官方 S2P 的最大奇异值约 1.0073（统一阈值 1.001），最大互易误差约 0.00233（统一阈值 1e-6），因此两项 `physical_rule_check` 如实记录为 `failed`。适配器不会为厂商数据临时放宽阈值。

## 已知边界

按固定差分 S-to-Z 公式得到的 250 MHz 等效电感约 6.183 nH、等效 Q 约 6.751；手册条件给出 5.6 nH 与 Q 最小 23。由于厂商夹具、去嵌入和手册测试方法并未证明与该公式等价，这不是可直接判定的实验符合性对比。底座正确做法是保留三套语义并记录换算公式，而不是调整数值制造一致。

## 第 4 组验收结果

- 单案例仓库：35 条实体记录、13 个 Artifact、15 个 HDF5 数据引用；
- 5 个场 Observable：电势、电场、焦耳损耗密度、温度、热流；
- 4 个 Run：2 个 `simulation_run` 与各自的 `data_processing` 子 Run；
- 1 条显式 one-way coupling edge：电场归一化 Run → 热求解 Run；
- 温度指标追溯得到 2 个 Observable、4 个 Run、12 个 Artifact、3 条 Provenance 和 1 条 coupling edge；
- 电/热求解收敛、耦合功率守恒、粗细网格温升差异均有阈值、结果、证据和执行时间；
- 任一伴随文件在入库前被篡改，bundle SHA-256 核对失败并进入 quarantine；
- 全套 39 个 Python 回归测试通过。

## 下一道门

不再开发第 5 类。先把第 3、4 组一起追加到用户共享 warehouse，确认器件类别达到 4 个、总仓库校验无 issue、全局 Parquet 索引可查询，并分别做一次电感指标和温度指标追溯。通过后再决定是增加第五类器件，还是进入智能体读取/检索接口。
